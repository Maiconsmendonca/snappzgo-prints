# SnappzGo — prints do app

Capturas de tela do app **SnappzGo** no emulador Android, em **10/nov/2026**, com dados reais restaurados do backup (conta maicon.mendonça).

> ⚠️ **Privado:** estas imagens contêm dados financeiros reais e e-mail. Mantenha este repositório **privado**.

## Estrutura

### Raiz — prints de viewport (fluxo de início)
Arquivos `01_…`–`43_…` na raiz: o passo a passo de **abertura, cadastro, login, restauração do backup e onboarding de permissões**, mais versões de viewport (sem costura) de várias telas.

## Limitações
- **Mapa / postos** dependem de GPS; o emulador não fornece, então aparecem na tela de permissão.
- **Raio-X** tem uma lista de 43 corridas muito longa — a montagem pega o começo dela.
- **Vale a pena** tem um resíduo da barra do teclado à esquerda (campo ficou focado na captura).
